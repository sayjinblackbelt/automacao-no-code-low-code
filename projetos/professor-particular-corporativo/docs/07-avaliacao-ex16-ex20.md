# 07 — Modelo de Avaliação — EX16 a EX20

**Projeto:** Professor Particular Corporativo de Competências Digitais  
**Domínio:** Microsoft Excel aplicado ao trabalho administrativo  
**Versão:** 0.1  
**Status:** modelo inicial para validação

## 1. Objetivo

Completar a primeira matriz de avaliação do MVP, avançando das competências técnicas para competências de análise, produção de informação e resolução autônoma de problemas.

Competências:

- EX16 — Limpeza e organização de bases
- EX17 — Tabela dinâmica
- EX18 — Interpretação de dados
- EX19 — Estruturação de relatórios
- EX20 — Resolução de problemas com Excel

## 2. Mudança de foco

Neste bloco, a pergunta deixa de ser apenas:

> "O aluno sabe utilizar este recurso?"

E passa a ser:

> "O aluno consegue utilizar diferentes recursos para resolver uma necessidade profissional?"

A avaliação deverá considerar raciocínio, estratégia, autonomia, qualidade e transferência.

## 3. EX16 — Limpeza e organização de bases

### Objetivo

Verificar se o aluno consegue identificar e corrigir problemas que impedem ou prejudicam a análise de uma base de dados.

### Tarefa diagnóstica

Fornecer uma base contendo alguns problemas intencionais, como:

- registros duplicados;
- espaços ou inconsistências de texto;
- datas em formatos diferentes;
- campos vazios;
- categorias escritas de formas diferentes;
- valores inadequados;
- cabeçalhos pouco claros.

Solicitar que o aluno prepare a base para análise.

### Evidências

- identificação dos problemas;
- correções apropriadas;
- preservação dos dados válidos;
- padronização;
- capacidade de explicar o que foi alterado.

### Indicadores de nível

**Nível 1:** não identifica problemas relevantes ou altera dados de maneira inadequada.

**Nível 2:** corrige problemas evidentes com orientação.

**Nível 3:** realiza limpeza básica de forma autônoma.

**Nível 4:** identifica diferentes tipos de inconsistência, escolhe métodos adequados e verifica a qualidade final.

**Nível 5:** estrutura procedimentos de preparação de dados reutilizáveis e considera prevenção de novos erros.

### Treino

Corrigir bases pequenas com problemas previamente indicados.

### Prática

Preparar uma base sem receber uma lista completa de problemas.

### Desafio profissional

Receber uma base aparentemente pronta, descobrir problemas que podem comprometer um relatório e preparar os dados para análise, justificando as principais alterações.

## 4. EX17 — Tabela dinâmica

### Objetivo

Verificar se o aluno consegue resumir e explorar uma base utilizando diferentes dimensões.

### Tarefa diagnóstica

Fornecer uma base de vendas com campos como:

- data;
- vendedor;
- setor;
- produto;
- categoria;
- valor.

Solicitar respostas para perguntas diferentes, por exemplo:

- total por vendedor;
- total por mês;
- total por categoria;
- comparação entre setores.

O aluno deverá decidir como estruturar a tabela dinâmica.

### Evidências

- seleção correta da base;
- organização adequada de linhas, colunas, valores e filtros;
- escolha coerente das dimensões;
- interpretação correta dos resultados.

### Indicadores de nível

**Nível 1:** não consegue criar ou compreender uma tabela dinâmica.

**Nível 2:** reproduz uma configuração seguindo instruções.

**Nível 3:** cria análises básicas autonomamente.

**Nível 4:** escolhe dimensões adequadas para responder diferentes perguntas.

**Nível 5:** utiliza tabelas dinâmicas de maneira estratégica, explora diferentes perspectivas e identifica limitações da análise.

### Treino

Criar tabelas dinâmicas seguindo perguntas e modelos.

### Prática

Responder perguntas de gestão utilizando diferentes configurações.

### Desafio profissional

Receber uma base e três perguntas de análise sem indicação do layout. O aluno deverá decidir como estruturar as tabelas necessárias.

## 5. EX18 — Interpretação de dados

### Objetivo

Verificar se o aluno consegue transformar resultados numéricos em conclusões úteis.

### Tarefa diagnóstica

Apresentar uma tabela ou conjunto de gráficos contendo dados de desempenho e solicitar que o aluno responda:

- o que aconteceu;
- quais resultados chamam atenção;
- quais diferenças são relevantes;
- que hipótese poderia explicar um resultado;
- que informação adicional seria necessária para confirmar a hipótese.

### Evidências

- leitura correta dos dados;
- distinção entre fato e interpretação;
- identificação de padrões e desvios;
- uso de evidências;
- reconhecimento de limitações.

### Indicadores de nível

**Nível 1:** descreve dados de maneira incorreta ou sem compreensão.

**Nível 2:** identifica informações evidentes com orientação.

**Nível 3:** interpreta corretamente resultados simples.

**Nível 4:** relaciona diferentes indicadores, identifica padrões e limitações.

**Nível 5:** produz análise crítica, formula hipóteses justificadas e indica quais dados adicionais seriam necessários para decisão.

### Treino

Perguntas objetivas sobre tabelas e gráficos.

### Prática

Escrever conclusões curtas a partir de indicadores.

### Desafio profissional

Receber um relatório e produzir uma síntese executiva de poucos parágrafos, separando claramente fatos observados de hipóteses.

## 6. EX19 — Estruturação de relatórios

### Objetivo

Verificar se o aluno consegue combinar dados, cálculos, análises e comunicação em um relatório funcional.

### Tarefa diagnóstica

Fornecer uma base e uma demanda profissional, como:

> "Prepare o relatório mensal de vendas para a coordenação."

O aluno deverá decidir quais informações apresentar e como organizá-las.

### Evidências

- objetivo claro;
- dados relevantes;
- cálculos corretos;
- organização lógica;
- visualizações adequadas;
- conclusões úteis;
- facilidade de utilização por terceiros.

### Indicadores de nível

**Nível 1:** produz um documento incompleto ou difícil de interpretar.

**Nível 2:** produz um relatório seguindo um modelo detalhado.

**Nível 3:** estrutura relatórios funcionais em situações conhecidas.

**Nível 4:** seleciona informações de acordo com público e objetivo.

**Nível 5:** produz relatórios consistentes, claros e orientados à decisão, identificando limitações e possíveis melhorias.

### Treino

Montar relatórios seguindo modelos.

### Prática

Criar um relatório mensal a partir de uma base.

### Desafio profissional

Receber apenas a demanda e os dados brutos e produzir uma versão pronta para ser utilizada por um gestor.

## 7. EX20 — Resolução de problemas com Excel

### Objetivo

Avaliar a capacidade de resolver uma situação nova sem indicar antecipadamente quais recursos do Excel devem ser utilizados.

### Tarefa diagnóstica/final

Apresentar um problema profissional aberto.

Exemplo:

> Uma empresa possui uma base de vendas. A gestão precisa identificar quais vendedores não atingiram a meta, quanto deixaram de vender em relação à meta, quais categorias apresentam maior queda e quais informações deveriam ser apresentadas em uma reunião.

O aluno deverá:

1. compreender a demanda;
2. analisar os dados;
3. identificar necessidades de tratamento;
4. escolher recursos;
5. construir a solução;
6. verificar resultados;
7. apresentar conclusões.

### Evidências

- compreensão do problema;
- planejamento;
- seleção adequada de recursos;
- execução;
- verificação;
- autonomia;
- qualidade;
- clareza da justificativa;
- capacidade de lidar com imprevistos.

### Indicadores de nível

**Nível 1:** não consegue estruturar uma estratégia para o problema.

**Nível 2:** resolve partes do problema com orientação significativa.

**Nível 3:** resolve uma situação conhecida utilizando recursos adequados.

**Nível 4:** resolve problemas novos com autonomia e consegue justificar as escolhas.

**Nível 5:** analisa o problema de forma sistêmica, cria uma solução robusta, verifica riscos, propõe melhorias e consegue explicar ou ensinar sua abordagem.

### Treino

Problemas estruturados com indicação parcial dos recursos possíveis.

### Prática

Problemas com objetivo definido e liberdade para escolher os recursos.

### Desafio

Problema aberto, com dados imperfeitos e requisitos parcialmente definidos.

## 8. Avaliação integrada final — Projeto Excel

As competências EX16–EX20 devem culminar em um projeto integrado.

### Cenário

O aluno recebe uma base realista de uma empresa fictícia, contendo volume suficiente para exigir tratamento e análise.

### Demanda

Preparar uma análise para uma reunião de gestão.

### Entregáveis

1. base limpa e organizada;
2. cálculos e indicadores;
3. análise por tabela dinâmica ou outro recurso adequado;
4. gráficos pertinentes;
5. relatório final;
6. conclusões e recomendações.

### Critérios

| Critério | Peso inicial sugerido |
|---|---:|
| Correção dos dados | 15% |
| Correção dos cálculos | 20% |
| Adequação das análises | 20% |
| Clareza da comunicação | 15% |
| Autonomia | 10% |
| Robustez/reutilização | 10% |
| Justificativa e interpretação | 10% |

Os pesos são hipóteses iniciais e deverão ser validados.

## 9. O projeto final não deve ser apenas uma prova

A avaliação final deve responder a uma pergunta mais importante:

> **"Esta pessoa consegue receber uma demanda digital de trabalho, organizar o problema, utilizar o Excel para resolvê-lo e entregar algo útil sem depender de instruções passo a passo?"**

Essa pergunta representa o objetivo maior do Professor Particular Corporativo.

## 10. Conclusão da matriz Excel v1

Com EX16–EX20, as 20 competências iniciais do domínio Excel estão descritas.

A próxima etapa deixa de ser simplesmente adicionar conteúdos e passa a ser construir o **motor de diagnóstico e personalização**.

**Perfil + objetivo profissional + evidências de avaliação**

para produzir:

**Mapa de competências + prioridades + trilha individual + próxima avaliação.**
