# 06 — Modelo de Avaliação — EX11 a EX15

**Projeto:** Professor Particular Corporativo de Competências Digitais  
**Domínio:** Microsoft Excel aplicado ao trabalho administrativo  
**Versão:** 0.1  
**Status:** modelo inicial para validação

## 1. Objetivo

Detalhar as competências EX11–EX15, nas quais o aluno passa de operações e cálculos para estruturação, controle e comunicação de dados.

Competências:

- EX11 — Tabelas do Excel
- EX12 — Formatação condicional
- EX13 — Funções de busca e referência
- EX14 — Validação de dados
- EX15 — Gráficos

## 2. Princípio

O foco deixa de ser apenas executar recursos e passa a ser **construir planilhas mais robustas e úteis para outras pessoas**.

O agente deverá observar:

- escolha do recurso;
- organização da solução;
- integridade dos dados;
- autonomia;
- clareza;
- capacidade de adaptar a solução;
- aplicação profissional.

## 3. EX11 — Tabelas do Excel

### Objetivo

Verificar se o aluno consegue transformar uma base em uma tabela estruturada e utilizar seus recursos para facilitar manutenção e análise.

### Tarefa diagnóstica

Fornecer uma base de aproximadamente 50 registros e solicitar:

1. transformar a base em tabela;
2. identificar corretamente os cabeçalhos;
3. utilizar filtros;
4. adicionar um novo registro;
5. verificar se a estrutura acompanha o novo registro;
6. utilizar referências/recursos estruturados quando apropriado.

### Evidências

- tabela criada corretamente;
- cabeçalhos claros;
- filtros funcionais;
- expansão adequada;
- preservação da integridade dos dados.

### Indicadores de nível

**Nível 1:** não compreende a finalidade de uma tabela estruturada.

**Nível 2:** cria tabela com orientação.

**Nível 3:** cria e utiliza tabelas autonomamente.

**Nível 4:** escolhe quando uma tabela melhora a manutenção e análise da base.

**Nível 5:** estrutura bases reutilizáveis, considerando manutenção, consistência e facilidade de uso.

### Treino

Converter pequenas bases em tabelas e explorar filtros.

### Prática

Estruturar uma base administrativa que recebe novos registros semanalmente.

### Desafio profissional

Receber uma planilha que cresce continuamente e propor uma estrutura que reduza retrabalho e erros de manutenção.

## 4. EX12 — Formatação condicional

### Objetivo

Verificar se o aluno consegue utilizar regras visuais para destacar informações relevantes automaticamente.

### Tarefa diagnóstica

Fornecer uma base com metas, resultados, datas ou status e solicitar que o aluno destaque automaticamente situações como:

- meta não atingida;
- valores acima de determinado limite;
- vencimentos próximos;
- duplicidades ou situações específicas.

### Evidências

- regra adequada ao problema;
- aplicação correta ao intervalo;
- atualização automática;
- destaque que facilita interpretação sem distorcer a informação.

### Indicadores de nível

**Nível 1:** não consegue criar ou compreender regras básicas.

**Nível 2:** aplica regras seguindo instruções.

**Nível 3:** cria regras simples autonomamente.

**Nível 4:** escolhe regras de acordo com o objetivo de análise e combina critérios quando necessário.

**Nível 5:** utiliza formatação condicional como parte de uma solução de comunicação e controle de dados.

### Treino

Regras simples por valor, texto e data.

### Prática

Criar um sistema visual de acompanhamento de metas.

### Desafio profissional

Receber uma planilha de acompanhamento e decidir quais situações merecem destaque automático para facilitar o trabalho de uma equipe.

## 5. EX13 — Funções de busca e referência

### Objetivo

Verificar se o aluno consegue relacionar informações entre tabelas e recuperar dados a partir de uma chave.

### Tarefa diagnóstica

Fornecer uma tabela principal e uma tabela auxiliar, por exemplo:

**Produtos:** código, descrição, categoria, preço.  
**Vendas:** código do produto, quantidade, vendedor.

Solicitar que o aluno recupere automaticamente descrição, categoria e preço para cada venda.

### Evidências

- identificação da chave de relacionamento;
- escolha adequada da função;
- referência correta às tabelas;
- tratamento de registros não encontrados;
- solução que continue funcionando para novos registros.

### Indicadores de nível

**Nível 1:** não compreende a relação entre tabelas.

**Nível 2:** utiliza uma função de busca seguindo modelo.

**Nível 3:** realiza buscas autonomamente em situações conhecidas.

**Nível 4:** escolhe entre alternativas como PROCX/PROCV conforme contexto e diagnostica erros.

**Nível 5:** estrutura soluções robustas de relacionamento de dados e considera manutenção, compatibilidade e tratamento de erros.

### Treino

Buscar informações usando uma chave simples.

### Prática

Relacionar duas tabelas administrativas.

### Desafio profissional

Receber duas bases de fontes diferentes e construir uma solução que permita enriquecer a base principal automaticamente.

## 6. EX14 — Validação de dados

### Objetivo

Verificar se o aluno consegue controlar entradas e reduzir inconsistências em uma planilha compartilhada.

### Tarefa diagnóstica

Fornecer uma planilha com campos como:

- status;
- setor;
- categoria;
- data;
- quantidade.

Solicitar a configuração de regras apropriadas para impedir ou reduzir entradas inválidas.

### Evidências

- regras adequadas ao campo;
- listas utilizadas quando apropriado;
- restrições numéricas ou de data;
- mensagens/instruções adequadas quando relevantes.

### Indicadores de nível

**Nível 1:** não reconhece a finalidade da validação.

**Nível 2:** configura regras simples com orientação.

**Nível 3:** utiliza validação adequadamente em tarefas conhecidas.

**Nível 4:** identifica campos de risco e escolhe mecanismos de controle apropriados.

**Nível 5:** projeta estruturas de entrada que reduzem erros e melhoram a qualidade da base.

### Treino

Criar listas e restrições simples.

### Prática

Preparar uma planilha para preenchimento por uma equipe.

### Desafio profissional

Analisar uma base com erros recorrentes de preenchimento e propor controles para reduzir esses erros.

## 7. EX15 — Gráficos

### Objetivo

Verificar se o aluno consegue transformar dados em uma visualização adequada à pergunta ou objetivo de comunicação.

### Tarefa diagnóstica

Fornecer dados de vendas por mês, vendedor e categoria e solicitar uma visualização que permita responder a uma pergunta específica.

O aluno deverá decidir:

- quais dados utilizar;
- qual tipo de gráfico;
- quais elementos apresentar;
- como organizar títulos e rótulos.

### Evidências

- seleção correta dos dados;
- escolha coerente do tipo de gráfico;
- clareza;
- título significativo;
- ausência de elementos desnecessários;
- capacidade de interpretar o gráfico produzido.

### Indicadores de nível

**Nível 1:** tem dificuldade para criar ou interpretar gráficos básicos.

**Nível 2:** cria gráficos seguindo modelo.

**Nível 3:** escolhe e produz gráficos adequados em situações conhecidas.

**Nível 4:** escolhe visualizações conforme a pergunta e o público.

**Nível 5:** utiliza visualização de dados para comunicar conclusões e identifica quando um gráfico pode induzir interpretação inadequada.

### Treino

Criar gráficos simples a partir de pequenas tabelas.

### Prática

Produzir gráficos para comparação, evolução temporal e distribuição.

### Desafio profissional

Receber uma base e a pergunta "Como estão evoluindo nossos resultados?" e decidir quais dados e visualização melhor respondem à pergunta.

## 8. Avaliação integrada EX11–EX15

### Cenário

O aluno recebe uma base de vendas de uma empresa fictícia.

Solicitações:

1. transformar a base em tabela;
2. controlar campos de preenchimento;
3. recuperar dados de uma tabela auxiliar;
4. destacar automaticamente resultados relevantes;
5. produzir um gráfico adequado para apresentação.

A tarefa deve avaliar se o aluno consegue combinar estrutura, controle, relacionamento e comunicação dos dados.

## 9. Critério especial — robustez

Nesta faixa, o agente deve começar a avaliar se a solução continua funcionando quando:

- novos registros são adicionados;
- valores são alterados;
- filtros são aplicados;
- a tabela cresce;
- aparecem dados inesperados.

Uma solução que funciona apenas para os dados originais não deve receber o mesmo nível de domínio de uma solução reutilizável.

## 10. Critério especial — comunicação

A partir de EX12 e principalmente EX15, a avaliação deve considerar o usuário final.

Pergunta orientadora:

> "Outra pessoa conseguiria entender e utilizar esta planilha sem que o autor estivesse presente?"
